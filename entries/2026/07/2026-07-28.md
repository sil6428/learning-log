## What I learned

- A portfolio reads more clearly when each project and interest has room for its own context.
- Responsive layouts need testing at several widths because navigation and visual cards fail in different ways.
- Public source needs a separate review for private files, unused assets, environment data, and deployment metadata.
- Route-level tests help catch broken links and missing project images before deployment.
