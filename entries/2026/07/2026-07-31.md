## What I learned

- One large raycast surface gives a powered-off monitor a clear interaction before smaller desktop targets become relevant.
- Separating visual state from hit-test state prevents invisible file targets from intercepting the first screen click.
- A CanvasTexture supports off, booting, and ready states without replacing the Three.js monitor model.
- A close camera angle still needs an explicit exit path and keyboard-accessible equivalent.
