## What I learned

- A safe crawler is mainly a policy and boundary problem. URL checks, DNS checks, redirect handling, resource limits, and explicit authorization matter as much as HTML parsing.
- Durable automation needs persisted state, leases, checkpoints, bounded retries, and clear stop conditions. A loop running in memory is not enough.
- Findings are stronger when reviewers can trace each claim to retained evidence and see how the score was produced.
- Human approval is only meaningful when it binds to the exact recipient and exact message content. Editing either must invalidate the approval.
- Backup work is incomplete until restore verifies hashes and succeeds against a clean destination.
- Private source can still support a portfolio claim when the public description is specific, measured, and careful not to expose operational details.
