## What I learned

- An old archive is useful when it is treated as evidence, not as a list of everything to publish.
- A useful student tool can demonstrate security thinking through data minimization, allowlisted reads, local storage, and honest release boundaries.
- Public material is easier to trust when the resume, profile, case studies, repository documentation, and tests agree on the same facts.

## Problem encountered

- Several older files used similar project names or reflected work at different stages. The solution was to prefer current repositories, measured outputs, and explicit verification over older summaries.
